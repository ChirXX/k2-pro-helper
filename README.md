# 3D Помощник

Карманный справочник по 3D-печати для Android: решение проблем, популярные принтеры (Creality, Bambu Lab, Prusa, Elegoo, Qidi, Anycubic, Voron), материалы и производители пластика, калькуляторы, видео, уход за принтером и заметки.

- `www/index.html` — само приложение (можно открыть в браузере).
- `android/` — Android-проект (Capacitor).
  - `PrinterWidget.java` + `PrinterNet.java` — виджет «Принтер» для главного экрана: статус, прогресс, температуры, снимок, кнопки (обновить, подсветка, пауза с повторным нажатием, камера). Сам опрашивает принтер по Wi-Fi (раз в ~2 мин во время печати, иначе раз в 30 мин), а пока приложение открыто — получает данные из него.
  - `HomePlugin.java` — мост JS ↔ Android (`Capacitor.Plugins.Home`): данные для виджета, кнопка «закрепить виджет», камера в окне «картинка в картинке» поверх главного экрана.
- APK собирается автоматически в GitHub Actions при каждом изменении в ветке `main`. Готовый файл — во вкладке **Releases**.
